## 🌐 Project Overview

Task Manager Pro is a full-stack MERN application that allows users to securely manage their daily tasks with authentication and protected routes.

The system provides:

- Secure user registration and login (JWT based)
- Personal task management (CRUD)
- Task status tracking (complete / pending)
- Responsive modern UI
- Cloud database (MongoDB Atlas)
- Backend + Frontend deployment

Each user can only access their own tasks, ensuring proper data isolation and security.

This project demonstrates full-stack architecture, REST API design, authentication middleware, and production deployment.
